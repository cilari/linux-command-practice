# Linux Command Practice

An interactive web-based terminal simulator for learning and practicing Linux commands. Perfect for beginners preparing for Linux certifications or anyone wanting to improve their command-line skills.

## 🚀 Features

- **13 Interactive Workshops** covering Linux fundamentals to advanced topics
- **Terminal Simulator** with 80+ working Linux commands
- **Progressive Learning** with step-by-step guided tasks
- **Knowledge Integration** - Learn key concepts before each task
- **Quizzes** to test your understanding
- **Progress Tracking** - Your progress is saved locally
- **Real-time Hints** - Get help when you need it

## 📚 Workshop Topics

### Day 1: Fundamentals
- Linux Fundamentals (filesystem, navigation, paths)
- Using Man Pages & Help
- File Operations (create, copy, move, delete)
- Text Operations (redirection, grep, pipes)

### Day 2: Permissions & Users
- File Permissions (chmod, ownership)
- Users and Groups (whoami, id, groups)

### Day 3: Storage
- Disk and Filesystem Management (df, du, mount)

### Day 4: System Administration
- Package Management (apt, dnf, systemctl)
- Networking Commands (ping, curl, dig, netstat)
- Process Management (ps, top, jobs, kill)
- Log Analysis (journalctl, grep, tail)
- System Troubleshooting

### Day 5: Automation
- Task Scheduling with Cron

## 🎯 Learning Approach

Each workshop includes:
1. **Tasks** - Hands-on exercises with validation
2. **Knowledge Boxes** - Key concepts and command explanations
3. **Hints** - Progressive help system
4. **Quizzes** - Test your understanding

## 🛠️ Technologies

- Pure JavaScript (no frameworks)
- HTML5 & CSS3
- Local Storage for progress tracking
- Responsive design

## 🚀 Getting Started

Simply open `index.html` in your web browser, or visit the live demo:

**[Try it now!](https://YOUR-USERNAME.github.io/linux-command-practice/)**

## 💡 Usage

1. Choose a workshop from the main menu
2. Read the task instruction
3. Click "Show Hint" to see key knowledge and hints
4. Type commands in the terminal
5. Complete all steps to unlock the quiz
6. Your progress is automatically saved

## 📖 Command Coverage

The simulator includes 80+ commands:
- **File Management**: ls, cd, pwd, mkdir, touch, cp, mv, rm, cat, etc.
- **Text Processing**: grep, sed, awk, cut, sort, uniq, wc
- **System Monitoring**: ps, top, free, df, du, uptime, vmstat
- **Networking**: ping, curl, wget, dig, netstat, lsof, ssh
- **Package Management**: apt, yum, dnf, rpm, dpkg
- **Service Management**: systemctl, service
- **Log Analysis**: journalctl, tail, dmesg, last
- **Process Control**: kill, bg, fg, jobs, nohup
- **And many more!**
